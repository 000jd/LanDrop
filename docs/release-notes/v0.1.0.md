# LanDrop v0.1.0

Send any file, folder, text or link to the device next to you — straight over
your Wi-Fi, with no cloud and no accounts.

## Install with one command (Linux & macOS)

```bash
curl -fsSL https://raw.githubusercontent.com/000jd/LanDrop/main/install/install.sh | bash
```

The installer detects your OS/CPU, downloads the matching asset plus
`SHA256SUMS.txt`, verifies the checksum, and installs `~/.local/bin/landrop`
(and the desktop app in a graphical session). Force the desktop app with
`--desktop`. Uninstall with:

```bash
curl -fsSL https://raw.githubusercontent.com/000jd/LanDrop/main/install/install.sh | bash -s -- --uninstall
```

## Highlights

- **Resumable uploads** — a dropped connection keeps the partial file; the sender
  asks `HEAD /api/v1/upload/{id}` for the offset and continues with
  `X-LanDrop-Offset` (three automatic retries).
- **Verification PINs and trusted peers** — every transfer/batch shows a
  `NNN-NNN` PIN, and trusted devices can skip the accept prompt.
- **Text and links** — send a URL or snippet like a file; it never touches disk.
- **QR onboarding and browser links** — inline SVG QR codes plus 15-minute
  `/d/{token}` downloads for phones without LanDrop installed.
- **Batches and multi-device sends** — one prompt per folder, accept/reject/cancel
  the whole batch at once, four uploads in flight per sender.
- **Android share sheet** — share files or text from any app; a Wi-Fi
  `MulticastLock` keeps mDNS discovery receiving while the app is visible.
- **Desktop polish** — tray icon, single instance, settings layout that fits
  without scrolling, and a **Clear history** button for finished transfers.
- **Integrity and safety** — streaming transfers, enforced sizes, SHA-256
  verification, sanitized paths, local-only settings/trust/history endpoints.
